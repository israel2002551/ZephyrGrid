# ZephyrGrid model artefacts

This folder contains versioned, reproducible model artefacts only. A model is
not production-eligible until it has an evaluation report, source dataset
version, feature contract, model version, and field-validation record.

`tdd2022_random_forest_benchmark.joblib`, when created, is a synthetic-data
pipeline benchmark. It must not be used to accuse customers of theft, trigger
enforcement, or represent expected Nigerian DisCo performance.
